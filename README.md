# TETLIS

ブラウザで動く落ち物パズル。**1台のキーボードで最大4人**まで同時に遊べる。

**依存ゼロ・ビルド不要**。`index.html` を開けばそのまま動く。
絵は絵文字、音は WebAudio の合成音で、素材ファイルを一切持たない。

---

## 動かす

```
index.html をブラウザで開く
```

サーバーが要る場合は `python -m http.server` などで配信する。

---

## 何ができるか

### 人数と対戦

| | |
|---|---|
| 1人 | ソロ・練習 |
| 2〜4人 | 同じキーボードで同時対戦 |

プレイヤーごとに **2D / 3D を選べる**（混在可）。

キー割り当ては4人ぶん独立している。

| | 移動 | 回転 | 落下 | ホールド |
|---|---|---|---|---|
| P1 | ←→↓ | ↑ / 右Ctrl | Enter | 右Shift |
| P2 | WASD | W / Q | Space | Tab |
| P3 | IJKL | I / U | O | N |
| P4 | テンキー | | | |

ゲームパッドとタッチ操作にも対応している。

### 遊び方の種類

- **マラソン** … レベルを上げながら続ける
- **スプリント** … 40ラインまでの速さを競う
- **ウルトラ** … 2分間のスコアアタック
- **対戦** … 消したラインが相手にお邪魔として送られる

### キャラクター

絵文字のキャラクターを選ぶ。それぞれ **飛ばす弾・色・合成音の声・必殺技** を持つ。
必殺技は **攻（攻撃）／妨（妨害）／防（防御）** の3種類に分かれている。

### 見た目と音

テーマ9種（クラシック / ネオン / ダーク / レトロ / パステル / サンセット / オーシャン / フォレスト / キャンディ / サイバー）。
BGM と効果音は合成音で、音量も個別に変えられる。

## 中身の話

### 操作感は数値で持っている

落ち物パズルの手触りは、ほとんどが入力まわりの数値で決まる。
そこを `src/config.js` に集めて、いじれるようにしてある。

```js
DAS_MS: 150,           // 押しっぱなしで動き出すまで
ARR_MS: 33,            // 動き出したあとの反復間隔
SOFT_DROP_MULT: 20,    // 下押しでの落下倍率
LOCK_DELAY_MS: 500,    // 接地してから固定されるまで
LOCK_RESET_LIMIT: 15,  // 動かして固定を遅らせられる回数の上限
```

`LOCK_RESET_LIMIT` を入れているのは、これが無いと**接地したまま動かし続けて永久に固定されない**ため。

### 対戦の釣り合い

```js
PENDING_GARBAGE_CAP: 12,     // お邪魔の溜まる上限
GARBAGE_PER_SPAWN: 4,        // 一度に降ってくる最大行数
PERFECT_CLEAR_ATTACK: 8,     // 全消しのボーナス
```

一度に全部降らせると復帰できないので、**溜める上限**と**一度に降る量**を分けている。

### ファイル構成

```
src/
  config.js        設定値（盤面・操作・対戦の数値）
  piece.js         ブロックの形と回転
  field.js         盤面と行消し
  game.js          1人ぶんのゲーム進行
  match.js         対戦の管理
  ai.js            コンピュータの手
  render.js        描画
  audio.js         効果音（合成）
  music.js         BGM（合成）
  fx.js            演出
  input.js         キー入力
  gamepad.js       ゲームパッド
  touch.js         タッチ操作
  menu.js          設定画面
  tetris3d.js      3Dモード
```
